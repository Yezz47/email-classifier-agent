# 智能邮件分类助手 - 使用指南

> 这是一份写给使用者的操作文档，无需任何编程知识，按步骤操作即可。

---

## 一、这个工具能做什么？

这是一个**全自动**的邮件管理助手，部署后它会：

| 功能 | 说明 |
|------|------|
| 每小时自动检查新邮件 | 后台自动运行，不需要你打开任何界面 |
| 智能分类邮件 | 自动识别邮件类型（重要/次重要/不重要） |
| 自动标记和归档 | 重要邮件自动标星，不重要邮件自动归档 |
| 重要邮件即时通知 | 收到重要邮件时，立即发邮件通知你 |
| 每日邮件总结 | 每天 23:30 自动发送当日邮件整理报告到你的邮箱 |

**你完全不需要手动操作，系统会自动帮你管理邮件。**

---

## 二、邮件分类规则

系统会自动将邮件分为三个等级：

### 🔴 重要（需立即关注）
- 课程相关：选课通知、课程变更、调课安排、作业截止提醒
- 考试相关：考试时间、考场安排、考试通知、成绩发布
- 放假通知：节假日放假安排、调课通知
- 黑雨/暴雨停课通知：恶劣天气停课、紧急停课通知

### 🟡 次重要（建议关注）
- 学校食品营养相关讲座、健康讲座
- 图书馆通知：借阅到期提醒、新书上架、图书馆活动
- 学术讲座、研讨会通知
- 奖学金/助学金申请通知

### ⚪ 不重要（可忽略）
- 招志愿者通知
- 社团宣传、社团招新
- 商业推广、广告邮件

---

## 三、自动处理规则

系统会按以下规则自动处理邮件：

| 邮件等级 | 自动操作 |
|----------|----------|
| 🔴 重要 | 自动标记星标 ⭐ + 立即发邮件通知你（含邮件跳转链接） |
| 🟡 次重要 | 自动标记星标 ⭐ |
| ⚪ 不重要 | 自动标记已读 + 归档（从收件箱移走） |

---

## 四、每日邮件总结

每天 **23:30（北京时间）**，系统会自动：

1. 获取你今天收到的所有邮件
2. 用 AI 进行智能分类
3. 生成一份精美的 HTML 报告，包含：
   - 📊 分类统计（重要/次重要/不重要各多少封）
   - 🔔 重要邮件摘要（含 Gmail 跳转链接，点击直接打开邮件）
   - 📋 所有邮件的明细列表
4. 通过邮件发送到你的邮箱

**报告示例：**
```
主题：2026年09月04日 邮件整理

📧 每日邮件整理 - 2026年09月04日

今日共收到 7 封邮件

📊 分类统计
  重要：2 封
  次重要：3 封
  不重要：2 封

🔔 重要邮件摘要
  📌 期末考试安排通知
     来自: 教务处
     🔗 在 Gmail 中打开 →
```

## 五、如何与助手对话？

虽然系统是全自动运行的，但你也可以随时和它对话：

| 你可以说 | 系统会做什么 |
|----------|-------------|
| "帮我看看今天的邮件" | 获取并分类今天的邮件 |
| "有哪些重要邮件？" | 筛选并展示重要邮件 |
| "生成今日邮件总结" | 立即生成并发送今日总结报告 |
| "帮我发一封邮件给 xxx" | 帮你发送邮件 |
| "把某封邮件标记为已读" | 执行标记操作 |

## 六、常见问题

### Q1: 系统什么时候开始自动运行？
A: 部署成功后立即开始。每小时整点自动检查新邮件，每天 23:30 发送总结报告。

### Q2: 我需要每天打开系统吗？
A: 不需要。系统全天候自动运行，你只需要查看邮箱收到的通知和总结报告。

### Q3: 如果分类不准确怎么办？
A: 你可以随时和助手对话，告诉它"重新分类某封邮件"或调整分类规则。

### Q4: 重要邮件的通知是什么样的？
A: 系统会发一封邮件到你的邮箱，标题类似"🔔 重要邮件提醒 - 2026年09月04日 14:00"，邮件内容包含重要邮件的主题、发件人、摘要，以及一个链接，点击可以直接在 Gmail 中打开该邮件。

### Q5: 系统会删除我的邮件吗？
A: 不会。"归档"只是把邮件从收件箱移到"所有邮件"文件夹，邮件不会被删除，随时可以找回。

### Q6: 如何修改分类规则？
A: 联系帮你搭建这个系统的开发者，他可以调整分类规则和自动处理逻辑。

## 七、注意事项

1. **确保邮箱 IMAP/SMTP 已开启**：Gmail 需要在设置中开启 IMAP 访问
2. **使用应用专用密码**：Gmail 需要开启两步验证后生成"应用专用密码"，不能用登录密码
3. **保持服务运行**：系统需要保持部署状态才能自动运行
4. **检查垃圾邮件文件夹**：系统发送的总结报告偶尔可能被归入垃圾邮件，请注意检查
