# 智能邮件分类助手 - 完整配置与使用教程

> 本教程从零开始，手把手教你完成所有配置。无需编程知识，按步骤操作即可。

---

## 第一部分：前期准备（约 15 分钟）

### 步骤 1：开启 Gmail 两步验证

1. 打开浏览器，访问 [Google 账户安全页面](https://myaccount.google.com/security)
2. 登录你的 Gmail 账号
3. 在"登录 Google"区域，找到 **「两步验证」**
4. 点击「两步验证」→ 点击「开始设置」
5. 按提示完成手机验证（接收短信或 Google 提示）
6. 确认两步验证已开启（状态显示为"已开启"）

> 为什么需要两步验证？因为 Gmail 不允许直接用登录密码连接第三方应用，开启两步验证后才能生成"应用专用密码"。

---

### 步骤 2：生成 Gmail 应用专用密码

1. 仍在 [Google 账户安全页面](https://myaccount.google.com/security)
2. 在搜索框中搜索 **「应用专用密码」** 或访问 [Google 应用密码页面](https://myaccount.google.com/apppasswords)
3. 在"应用"下拉框中选择 **「邮件」**
4. 在"设备"下拉框中选择 **「其他（自定义名称）」**
5. 输入名称，例如：`邮件分类助手`
6. 点击 **「生成」**
7. 屏幕上会显示一个 **16 位密码**（格式类似 `abcd efgh ijkl mnop`）
8. **立即复制并保存这个密码**（关闭页面后就看不到了）

> 注意：这个密码不是你的 Gmail 登录密码！是专门给邮件助手用的。

---

### 步骤 3：确认 Gmail IMAP 已开启

1. 打开 Gmail 网页版
2. 点击右上角 **齿轮图标** → 「查看所有设置」
3. 切换到 **「转发和 POP/IMAP」** 标签页
4. 在"IMAP 访问"区域，确认已选择 **「启用 IMAP」**
5. 点击页面底部的 **「保存更改」**

---

## 第二部分：平台配置（约 10 分钟）

### 步骤 4：配置邮箱集成

1. 打开 Coze Coding 平台，进入你的项目
2. 点击顶部导航栏的 **「设置」**
3. 找到 **「集成」** 或 **「Integration」** 选项
4. 找到 **Email (IMAP/SMTP)** 集成，点击配置
5. 填写以下信息：

| 配置项 | 填写内容 | 说明 |
|--------|----------|------|
| `imap_server` | `imap.gmail.com` | Gmail 的 IMAP 服务器地址 |
| `imap_port` | `993` | IMAP 端口（SSL） |
| `smtp_server` | `smtp.gmail.com` | Gmail 的 SMTP 服务器地址 |
| `smtp_port` | `465` | SMTP 端口（SSL） |
| `account` | 你的 Gmail 地址 | 例如 `yourname@gmail.com` |
| `auth_code` | 步骤2生成的16位密码 | 应用专用密码，去掉空格 |

6. 点击 **「保存」** 或 **「确认」**

---

### 步骤 5：配置工作流 API Token

1. 仍在项目页面，点击顶部导航栏的 **「环境变量」**
2. 确认当前在 **「开发环境」** 标签页
3. 点击 **「+ 新建变量」**
4. 填写：
   - **Key**: `COZE_WORKFLOW_API_TOKEN`
   - **Value**: 你的工作流 API Token（从部署页面的 API 文档中复制）
5. 点击 **「确认」**
6. 切换到 **「生产环境」** 标签页，重复步骤 3-5（生产环境也需要配置）

> 如果不确定 Token 是什么：打开项目的「部署」页面 → 找到「执行工作流」→ 在 Header 区域点击「API Token」→ 复制显示的 Token。

---

### 步骤 6：部署项目

1. 点击右上角的 **「部署」** 按钮
2. 等待打包 → 构建 → 部署完成（约 2-5 分钟）
3. 部署成功后，页面会显示「部署成功」

---

## 第三部分：验证系统是否正常运行

### 步骤 7：检查定时任务是否启动

部署成功后，系统会自动启动两个定时任务：

| 任务 | 执行时间 | 做什么 |
|------|----------|--------|
| 每小时自动邮件管理 | 每小时整点（如 10:00, 11:00...） | 获取新邮件 → 分类 → 标记 → 重要邮件发通知 |
| 每日邮件总结 | 每天 23:30 | 生成当日邮件报告 → 发送到邮箱 |

**验证方法：**
1. 等待下一个整点（或等到 23:30）
2. 检查你的 Gmail 收件箱
3. 应该能收到来自"邮件管理助手"的通知邮件或总结报告

**如果没有收到：**
- 检查垃圾邮件文件夹
- 确认邮箱集成配置正确（特别是应用专用密码）
- 确认环境变量已配置

## 第四部分：日常使用

### 系统自动运行（无需操作）

部署完成后，你**什么都不用做**，系统会自动：

```
每小时整点
  ↓
自动检查最近1小时的新邮件
  ↓
AI 智能分类（重要/次重要/不重要）
  ↓
自动标记：重要→标星⭐ | 次重要→标星⭐ | 不重要→已读+归档
  ↓
如有重要邮件 → 立即发邮件通知你（含跳转链接）

每天 23:30
  ↓
获取当日所有邮件
  ↓
AI 分类统计 + 生成 HTML 报告
  ↓
发送总结邮件到你的邮箱
```

### 主动查询（可选）

如果你想主动查看邮件，可以在对话界面输入：

| 输入 | 效果 |
|------|------|
| `帮我看看今天的邮件` | 获取并展示今天的邮件列表和分类 |
| `有哪些重要邮件？` | 只显示重要等级的邮件 |
| `生成今日邮件总结` | 立即生成并发送今日总结（不用等到 23:30） |
| `最近有考试相关的邮件吗？` | 搜索特定类型的邮件 |
| `帮我发一封邮件给 xxx@xxx.com` | 发送邮件 |

## 第五部分：邮件分类规则详解

### 🔴 重要（需立即关注）

系统会自动标记星标 ⭐，并**立即发邮件通知你**。

包含以下类型的邮件：
- **课程相关**：选课通知、课程变更、调课安排、作业截止提醒
- **考试相关**：考试时间、考场安排、考试通知、成绩发布
- **放假通知**：节假日放假安排、调课通知
- **停课通知**：黑雨/暴雨停课、恶劣天气紧急停课
- **其他紧急学术事务**

### 🟡 次重要（建议关注）

系统会自动标记星标 ⭐，但不会发即时通知（会在每日总结中展示）。

包含以下类型的邮件：
- 学校食品营养相关讲座、健康讲座
- 图书馆通知：借阅到期提醒、新书上架、图书馆活动
- 学术讲座、研讨会通知
- 奖学金/助学金申请通知

### ⚪ 不重要（可忽略）

系统会自动标记已读并归档（从收件箱移走，但不会删除）。

包含以下类型的邮件：
- 招志愿者通知
- 社团宣传、社团招新
- 商业推广、广告邮件
- 其他非学术类通知

## 第六部分：每日总结报告说明

每天 23:30 你会收到一封邮件，主题格式为：

```
2026年09月04日 邮件整理
```

报告内容包括：

1. **📊 分类统计** — 今天收到多少封邮件，各等级分别多少封
2. ** 重要邮件摘要** — 每封重要邮件的主题、发件人、摘要，附带「🔗 在 Gmail 中打开」链接
3. **📋 邮件明细** — 所有邮件的完整列表，包含发件人、主题、分类、摘要

> 点击「🔗 在 Gmail 中打开」链接，会直接跳转到 Gmail 中对应的邮件页面。

## 第七部分：常见问题与故障排除

### Q1: 收不到每日总结邮件怎么办？

**排查步骤：**
1. 检查垃圾邮件文件夹
2. 确认 Gmail 地址填写正确
3. 确认应用专用密码未过期（如果修改了 Google 密码，应用密码会失效，需要重新生成）
4. 确认 IMAP 已开启

### Q2: 系统没有自动分类邮件？

**排查步骤：**
1. 确认项目已成功部署（不是"部署中"状态）
2. 确认环境变量 `COZE_WORKFLOW_API_TOKEN` 已配置
3. 等待下一个整点，系统每小时自动运行一次

### Q3: 应用专用密码失效了怎么办？

1. 重新访问 [Google 应用密码页面](https://myaccount.google.com/apppasswords)
2. 删除旧的 `邮件分类助手` 密码
3. 重新生成一个新密码
4. 回到 Coze Coding 平台 → 设置 → 集成 → Email，更新 `auth_code` 为新密码
5. 重新部署项目

### Q4: 分类规则可以修改吗？

可以。联系帮你搭建系统的开发者，他可以调整分类规则和自动处理逻辑。

### Q5: 系统会删除我的邮件吗？

**不会。** "归档"只是把邮件从收件箱移到"所有邮件"文件夹，邮件不会被删除。你可以在 Gmail 的"所有邮件"标签中找到归档的邮件。

### Q6: 我想取消自动运行怎么办？

联系开发者，他可以关闭定时任务或调整运行频率。

### Q7: 支持非 Gmail 邮箱吗？

目前系统针对 Gmail 优化。如果使用其他邮箱（如 QQ、163、Outlook），需要修改 IMAP/SMTP 服务器配置，并调整 Gmail 特有的文件夹名称（如 `[Gmail]/All Mail`）。
