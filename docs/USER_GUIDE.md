# 智能邮件分类助手 - 完整使用教程

> 本教程专为零基础用户设计，全程大白话，按步骤操作即可。

---

## 第一部分：这个工具能做什么？

部署完成后，你会拥有一个**全天候自动管理邮件**的 AI 助手：

| 功能 | 说明 |
|------|------|
| **自动分类** | 每小时自动检查新邮件，按重要程度分为三级 |
| **自动标记** | 重要邮件自动标星⭐，不重要邮件自动归档 |
| **即时通知** | 收到重要邮件时，立即发邮件通知你（含跳转链接） |
| **每日总结** | 每天 23:30 自动发送当日邮件总结报告到你的邮箱 |
| **主动查询** | 随时可以问助手"今天有哪些邮件？" |

**你不需要做任何事情**，系统会自动运行。

## 第四部分：邮件分类规则

助手会自动将邮件分为三个等级：

### 🔴 重要（需立即关注）

**系统会自动：**
- 标记星标 ⭐
- **立即发邮件通知你**（含 Gmail 跳转链接）

**包含以下类型：**
- 课程相关：选课通知、课程变更、调课安排、作业截止提醒
- 考试相关：考试时间、考场安排、考试通知、成绩发布
- 放假通知：节假日放假安排、调课通知
- 停课通知：黑雨/暴雨停课、恶劣天气紧急停课
- 其他紧急学术事务

### 🟡 次重要（建议关注）

**系统会自动：**
- 标记星标 ⭐
- 在每日总结中展示（不发即时通知）

**包含以下类型：**
- 学校食品营养相关讲座、健康讲座
- 图书馆通知：借阅到期提醒、新书上架、图书馆活动
- 学术讲座、研讨会通知
- 奖学金/助学金申请通知

###  不重要（可忽略）

**系统会自动：**
- 标记已读
- 归档（从收件箱移走，但不会删除）

**包含以下类型：**
- 招志愿者通知
- 社团宣传、社团招新
- 商业推广、广告邮件
- 其他非学术类通知

3. **分类明细表格**
   - 所有邮件的列表

4. **重要时间节点**
   - 作业截止日期
   - 考试时间
   - 其他需要关注的时间

### 报告样式
- HTML 格式，美观易读
- 重要邮件用黄色背景高亮
- 链接可直接点击跳转

## 第六部分：系统自动运行说明

### 定时任务

部署完成后，系统会自动启动两个定时任务：

| 任务 | 执行时间 | 做什么 |
|------|----------|--------|
| **每小时自动管理** | 每小时整点（如 10:00, 11:00...） | 获取新邮件 → 分类 → 标记 → 重要邮件发通知 |
| **每日总结** | 每天 23:30 | 生成当日邮件报告 → 发送到邮箱 |

### 运行流程图

```
每小时整点
  ↓
自动检查最近 1 小时的新邮件
  ↓
AI 智能分类（重要/次重要/不重要）
  ↓
自动标记：重要→标星⭐ | 次重要→标星⭐ | 不重要→已读 + 归档
  ↓
如有重要邮件 → 立即发邮件通知你（含跳转链接）

每天 23:30
  ↓
获取当日所有邮件
  ↓
AI 分类统计 + 生成 HTML 报告
  ↓
发送总结邮件到你的邮箱
```

### 你需要做什么？

**答案是：什么都不用做！**

系统会自动运行，你只需要：
1. 定期查看邮箱中的通知邮件和总结报告
2. 如果想主动查询，随时打开对话界面问助手

## 第七部分：常见问题（FAQ）

### Q1：我需要一直开着电脑吗？
**不需要。** 系统部署在云端，24 小时运行，你的电脑可以关机。

### Q2：为什么没有收到 23:30 的总结邮件？
可能原因：
1. 检查垃圾邮件文件夹
2. 确认邮箱配置正确（IMAP/SMTP/应用密码）
3. 确认项目已部署成功
4. 在对话界面输入"生成今日邮件总结"手动触发一次

### Q3：分类不准确怎么办？
可以在对话中告诉助手：
- `这封邮件应该是重要的`
- `以后类似 xxx 的邮件都归类为重要`

助手会学习你的反馈（需要重新部署才能生效）。

### Q4：如何修改分类规则？
联系帮你部署的朋友，让他修改配置后重新部署。

### Q5：支持其他邮箱吗（如 QQ 邮箱、 Outlook）？
目前支持所有 IMAP/SMTP 邮箱，但需要修改服务器配置：

| 邮箱 | IMAP 服务器 | SMTP 服务器 |
|------|------------|------------|
| Gmail | imap.gmail.com:993 | smtp.gmail.com:465 |
| QQ 邮箱 | imap.qq.com:993 | smtp.qq.com:465 |
| Outlook | outlook.office365.com:993 | smtp.office365.com:587 |
| 163 邮箱 | imap.163.com:993 | smtp.163.com:465 |

### Q6：如何停止自动运行？
联系帮你部署的朋友，让他停止部署或关闭定时任务。

### Q7：邮件会被删除吗？
**不会。** "归档"只是把邮件从收件箱移到"所有邮件"文件夹，不会删除任何邮件。
